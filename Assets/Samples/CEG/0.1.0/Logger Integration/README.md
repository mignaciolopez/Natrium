Logger Example

This sample demonstrates how to use the basic ECS tools from the ECS Tools package.

## What's Included
- Simple component definitions
- Basic system implementations
- Example scene setup

## How to Use
1. Import this sample into your project
2. Open the `BasicECSExample` scene
3. Press Play to see the system in action

## Files Description
- `ExampleComponent.cs` - Component definition
- `ExampleSystem.cs` - System implementation
- `BasicECSExample.unity` - Demo scene
